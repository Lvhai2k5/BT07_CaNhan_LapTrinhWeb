## 🌟 Giới thiệu

- **Thymeleaf + Thymeleaf Layout Dialect**

Các chức năng chính:
- ✅ Thêm, sửa, xóa danh mục  
- ✅ Tìm kiếm theo tên/mô tả  
- ✅ Phân trang danh sách  
- ✅ Layout chuyên nghiệp (header, content, footer)
